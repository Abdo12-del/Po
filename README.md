# عرض مشروع التخرّج: تيسلا رودستر والفيزياء

الموقع نفسه هو عرض عربي تفاعلي من سبع شرائح، وليس صفحة موقع تتضمن عرضاً منفصلاً. يستخدم غلافاً أكاديمياً مستوحى من بنية مذكرات التخرّج الجزائرية (الجهة التعليمية، عنوان المذكرة، التخصص، الإعداد والإشراف)، مع هوية ورقية هادئة ولمسات كحلية وذهبية. يتضمن نموذج Roadster ثلاثي الأبعاد قابلاً للتدوير، وانتقالات GSAP، ومحاكاة تعليمية لنسبة الدفع إلى الوزن. تبقى الرسمة المتجهية الاحتياطية ظاهرة إن لم يتوفر WebGL.

قبل المناقشة، استبدل الحقول بين الأقواس المربعة ببيانات الطالب والمؤسسة والتخصص والشهادة الفعلية.

## التشغيل

```sh
npm install
npm run dev
```

لإنشاء نسخة إنتاجية والتحقق منها:

```sh
npm run build
npm run preview
```

## مكتبات العرض

- [Three.js](https://github.com/mrdoob/three.js) — نموذج السيارة ثلاثي الأبعاد وعناصر المشهد.
- [GSAP](https://github.com/greensock/GSAP) — توقيت انتقالات الشرائح وحركة النموذج.
- Vite — خادم التطوير وتجميع الوحدات.

ترخيص كل مكتبة يبقى وفق ملف الترخيص في مستودعها الأصلي.
